#+title: Deck Runtime Qualification
#+language: en

The Marlin package build publishes the qualification program under
=marlin-agent-core/programs/bench= on =GERBIL_LOADPATH=. Cargo's
=mailbox-benchmark= feature links that program for the =mailbox= and
=context_profile= workloads. The program reuses the production Deck ABI
and adds the benchmark entry points.
