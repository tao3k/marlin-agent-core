#+TITLE: Marlin Scheme Package
#+LANGUAGE: en
#+FILETAGS: :marlin:scheme:

=gerbil.pkg= declares AI Agentic Lab as the sole direct package dependency.
Lab supplies Yuanxu and the POO contracts. =init.ss= selects the Marlin
profile.

| Role | Responsibility |
|------+----------------|
| =modules/*/types.ss= | Declare the POO contract for a module's scope. |
| =modules/*/objects.ss= | Supply default policy objects. |
| =modules/*/config.ss= | Validate the chosen values against the contract. |
| =modules/*/interface.ss= | Publish the scope and its declared features to Yuanxu. |
| =policy/= | Evaluate model routing, hooks, strategies, and continuations. |
| =projection/= | Prepare typed values for the Rust adapter. |
| =c-abi/= | Own the C entry points and their bindings. |
| =t/= | Exercise policy composition, projections, and receipt fixtures. |

Gerbil compiles the C link units through Gambit and executes policy in the
Scheme VM. The Rust adapter owns typed requests, authorization, and receipts.

Install the package dependency with =just scheme-deps=. CI installs the SDK
with the bridge's =setup-gerbil= action, prepares the pinned revisions with
Lab's =runtime-dependencies.ss=, and installs them with =gxpkg=. Run
=just scheme-package-gate= to initialize the VM and call
=GerbilRuntime::build_package= and =GerbilRuntime::test_package=. The
package =build.ss= supplies the build spec to Gerbil's standard builder.
Run =just agent-policy-routing-native-gate= for the linked C ABI selector.

The recorded loop-case trace in =t/fixtures/loop-case-trace.v1= was exported
from Marlin =5cdd0b1b= using Gerbil =v0.18.2-4-gadd92248=. Rust tests use it
to exercise typed receipt validation, no-live model denial, and replay.
