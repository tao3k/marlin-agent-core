#+title: Marlin / ui-tui - Terminal program
#+language: en

* Responsibility

Declares the terminal program entry as a selected Module. It starts with the
validated UI scope, so drawing the first frame does not acquire Lab Context or
open an agent session. Other UI modules own the workbench behavior.

* Interface and contracts

=interface.ss= declares the Module. =types.ss= and =config.ss= own its contracts
and scope assembly. =UiTuiScope= publishes =program-entry=. The Build role
includes that entry in the unified =std-make-spec=.
Consumers access selected exports through =marlin-agent-core.init.exports=.

* Build and verification

[[file:../init.ss][init.ss]] selects this module. Its Build role, if present,
contributes to the package's =std-make-spec=. See the
[[file:../README.org][Scheme package README]] for the shared build and test commands.

UI package tests exercise the real Ratatui mapping through the Scheme test
window. Terminal startup and exit are verified with PTY tests.
