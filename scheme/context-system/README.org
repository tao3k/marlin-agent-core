#+title: Marlin / Context System
#+language: en

* Responsibility

Adapts Lab Context, Org source and causal evidence to Marlin's Context System.

* Interface and contracts

=interface.ss= declares the Module. =types.ss= and =config.ss= admit its
scope. Deck and the Context ABI access the same selected scope through
=marlin-agent-core.init.exports.Marlin.context-system=.

* Build and verification

[[file:../init.ss][init.ss]] selects this module. Its Build role, if present,
contributes to the package's =std-make-spec=. See the
[[file:../README.org][Scheme package README]] for the shared build and test commands.
