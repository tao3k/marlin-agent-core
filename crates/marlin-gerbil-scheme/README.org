#+title: Marlin Gerbil Scheme

This crate owns the Rust projection of Scheme VM requests, values, and
receipts. The [[file:../../scheme/README.org][workspace Scheme package]] owns the
Gerbil build spec and the Marlin policy modules. Its direct dependency is
AI Agentic Lab.

The policy routing and Deck runtime link units contain Gerbil code compiled
through Gambit C. The runtime exchanges typed values through the C ABI and
Rust validates proposals before execution.

Use ~just scheme-package-gate~ for the Scheme package and
~just agent-policy-routing-abi-gate~ for the linked routing selector.
