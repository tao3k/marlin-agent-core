#+title: Marlin Agent Context

Context owns typed admission requests, source identities and Lab scope
projections. Scheme owns Org parsing, fields, queries and contract semantics.
There is no Rust Orgize dependency or separate Orgize runtime to initialize.

* Scheme boundary

The =gerbil-scheme-abi= feature supplies rooted-value conversion and linked
Context entry points. Deck uses these in its existing VM. The =gerbil= feature
also exposes =ContextOrgModule= for package-host access to the same selected
publication. Callers supply the owning =GerbilRuntime= explicitly.

=ContextOrgModule::open= retains a source-backed Scheme graph. =project=
returns source text, typed Element identities, parent relationships and UTF-8
byte spans. =fields= queries parser-owned fields in bounded batches. Element
identities belong to one opened source; another source's ordinal cannot be
substituted. Contract-source operations project Lab identities, generations,
digests and anchors. They preserve Scheme failures and explicit bounds.

The adapter lives in =scheme/context-system= and delegates to Lab's Context and
Scheme Orgize interfaces. Rust checks types, ownership, bounds and byte spans;
it does not parse Org text or reimplement contract evaluation.

* Host responsibilities

=org-source= exposes source persistence. =org-memory= adds a typed host cache
and local query/view projections; =org-workflow= adds release-status handoff.
=MemoryOrgWorkspace::apply_projection= accepts already projected nodes and
contract facts. The raw-text document loader, automatic store-to-parser query
helpers, Rust standard-contract library and exclusive parser startup API have
been removed. Source interpretation must use the Scheme boundary above.

=ContextOrgMemoryQuery= correlates a typed Context request with its local host
projection. Identity consistency and cached facts do not establish current-use
admission, source authentication or durable commit. The file store performs
individual replacements; it is not a transactional turn journal.

The TUI journal has not yet been migrated to a complete Org turn journal.
No context compression is introduced. See
[[file:../../docs/40-rfcs/40.181-context-org-ownership.org][Context-owned Org architecture]].
