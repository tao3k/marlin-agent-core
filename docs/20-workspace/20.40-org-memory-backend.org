* 20.40 Org Memory Backend
:PROPERTIES:
:ID: docs-20-40-org-memory-backend
:KIND: backend
:STATUS: active
:END:

=marlin-agent-context::org::MemoryOrgWorkspace= is the in-memory typed fact
cache and query/view projection. It accepts structured =OrgNode= records and
already produced contract facts through =apply_projection=. It preserves
producer outcomes, including failed validation, without evaluating contracts.

Raw documents are opened through the [[file:20.30-org-workspace-backend.org][Scheme Org boundary]]. The cache has no
raw-text loader or implicit store-to-parser path. Source interpretation and
contract semantics remain in Scheme; Rust supplies host storage, correlation,
query/view records and release-status handoff.

** Project Memory Query Boundary

Project-memory recall consumes typed query context and recall terms over
explicitly projected records. It retains source spans where supplied and
builds bounded graph/context results. Store discovery and Scheme projection
must be composed explicitly by the owner; loading every stored document is
not an implicit cache operation.

The cache is a local read model. Matching identities or cached contract facts
do not prove source authenticity, current-use admission or disclosure policy.

** Boundary
- Consumes typed records; does not parse Org or evaluate contracts.
- Preserves source provenance supplied by the producer.
- Does not grant execution authority when facts are inserted.
- Does not replace Lab's Context/Session lifecycle or a durable turn journal.
