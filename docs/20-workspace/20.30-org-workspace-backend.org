* 20.30 Org Workspace Backend
:PROPERTIES:
:ID: docs-20-30-org-workspace-backend
:KIND: protocol
:STATUS: active
:END:

Org source interpretation belongs to Scheme. Marlin's =scheme/context= uses
Lab's selected Context and Orgize modules through the existing Gerbil VM.
There is no separate Rust Org workspace/parser package.

=marlin-agent-context::gerbil_org::ContextOrgModule= supplies the typed host
boundary: open a rooted source, project Elements and query bounded fields.
The graph preserves original text, parent relationships and UTF-8 byte spans.
Element identities belong to the source instance that produced them.

** Boundary
- Scheme owns Org parsing, field semantics and contract evaluation.
- Rust checks typed values, source ownership, bounds and byte positions.
- The host store and fact cache consume explicit source/projection results.
- An Element graph does not establish durable commit or execution authority.

See [[file:../40-rfcs/40.181-context-org-ownership.org][Context-owned Org architecture]] for limits and the unfinished durable journal.
